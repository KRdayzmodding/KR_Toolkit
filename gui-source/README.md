# [KR] DevToolkit — исходники окон

Здесь лежат исходники **окон** тулз [KR] DevToolkit — программ `*_GUI.exe`.
Они распространяются на условиях **GNU GPL версии 3** (текст — в файле
[LICENSE](LICENSE)), потому что построены на библиотеке
[PySide6-Fluent-Widgets](https://github.com/zhiyiYo/PyQt-Fluent-Widgets/tree/PySide6)
(qfluentwidgets), которая сама распространяется по GPL-3.0.

## Что здесь есть и чего нет

Окна только показывают: списки файлов, настройки, ход работы, логи. Всю работу
делают **командные строки** — отдельные программы `Имя.exe` (без `_GUI`),
которые ставятся вместе с тулкитом. Окно вызывает их как обычные программы —
передаёт аргументы и читает их вывод (события JSON, по одному в строке).

Командные строки самодостаточны: работают без окон, ими пользуются из своих
скриптов, и qfluentwidgets они не используют. Это отдельные программы со своей
лицензией, их исходники здесь не публикуются.

Значит, на основе этих исходников можно сделать свои окна или написать свои с
нуля — так, как вам удобно, лишь бы ваши окна, построенные на этом коде,
оставались под GPL-3.0.

## Состав

- `desktop/<тулза>/` — окно каждой тулзы: `dev_toolkit` (лаунчер),
  `project_builder`, `addon_signer`, `sound_converter`, `imageset_editor`,
  `texture_editor`, `batch_tools` (одно окно на пять массовых конвертеров);
- `desktop/qts_ui/` — общий вид окон;
- `desktop/kr_icons.py`, `desktop/icons/` — значки;
- `desktop/kr_state.py` — где окна хранят размер и настройки;
- `kits/*/version.py`, `kits/*/__init__.py` — только название и версия тулзы
  для заголовка окна, без логики.

Состав пакета собирается автоматически из того, что реально лежит в выпущенных
`*_GUI.exe`, поэтому исходники соответствуют выложенной версии. Исходники
прежних версий — в истории этого репозитория.

## Сборка и запуск

Нужны Python 3.11 и пакеты `PySide6`, `PySide6-Fluent-Widgets`, `numpy`, `Pillow`:

```
pip install PySide6 PySide6-Fluent-Widgets numpy Pillow
```

Окно запускается из своей папки, например:

```
cd desktop/project_builder
python entry.py
```

В выпуске окна собраны PyInstaller в одну папку с командными строками
(`--windowed`, точка входа — `entry.py` тулзы, у массовых конвертеров —
`desktop/batch_tools/<конвертер>.py`, значки — `desktop/icons`).

Запущенное из исходников окно зовёт командную строку как `python -m <кит>`, а
киты здесь не публикуются. Для работы замените в функции `cli_command` (у
каждого окна своя: `worker.py`, `runner.py`, `remote.py`, `menu.py`; у окна
обновлений — `command` в `qts_ui/updates_ui.py`) вызов на путь к `Имя.exe` из
папки установки тулкита.
