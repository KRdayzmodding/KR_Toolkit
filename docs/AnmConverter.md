# [KR] ANM Converter — анимации ANM ⇄ TXA

Анимации ANM → TXA и обратно. Окно — общее для массовых конвертеров:
[как пользоваться](batch_tools.md).

## Что умеет

- `x.anm` → `x.txa` и `x.txa` → `x.anm`, оба направления за один прогон.
- TXA — в формате Workbench и Blender-плагина DayZ Animation Tools; события и
  custom properties — штатными блоками `$events` и `$custProps`.
- То, чего в формате TXA нет, а для игры важно (версия ANM, флаги регионов
  костей, их порядок, точное квантование), сохраняется в самом TXA
  комментариями `// kr: …`. Другие программы их пропускают, а при обратной
  конвертации неправленый файл возвращается в ANM байт в байт.

## Командная строка

```
AnmConverter.exe x.anm            → x.txa рядом
AnmConverter.exe x.txa            → x.anm рядом
AnmConverter.exe "P:\мод\anims"   обе стороны за один прогон
```

Общие ключи — [здесь](batch_tools.md#общие-ключи-командной-строки).

## Важно знать

- Конвертируется только сам файл: ничего не берётся из `.asi`, ikpose и других
  анимаций.
- TXA, сделанный в другой программе, комментариев `// kr:` не несёт. ANM тогда
  пишется со значениями по умолчанию, и отчёт предупреждает об этом: флаг 0 у
  костей спины превращает клип-дельту в абсолютный.
