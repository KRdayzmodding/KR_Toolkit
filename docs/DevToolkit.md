# [KR] DevToolkit — лаунчер

Главное окно тулкита: отсюда запускаются все тулзы, здесь же включаются пункты
меню проводника и выбираются версии.

Ярлык **[KR] DevToolkit** — на рабочем столе и в меню «Пуск».

## Вкладка «Приложения»

Карточки всех тулз с окном: название, что делает, версия. Щелчок по карточке
(или Enter на карточке в фокусе) — запуск. Тонкая полоска внизу карточки
показывает, что щелчок принят: окно тулзы появится через секунду-две.

На карточке видно и состояние версии: `0.3.2 → 0.4.0` — есть новая,
`0.1.4 · устарела` — стоит устаревшая.

## Вкладка «Настройки»

**Тема оформления** — системная, светлая или тёмная, одна на все тулзы. Открытые
окна перекрашиваются сразу, перезапускать их не нужно.

### Меню проводника

Пункты для правого клика по файлам:

| Файл | Пункт | Что делает |
|---|---|---|
| `.pbo` | Распаковать PBO | целиком, как [PBO Unpacker](PboUnpacker.md) |
| `.p3d` | P3D → MLOD | как [Model Converter](ModelConverter.md) |
| `.bin` | Разбинарить | `config.bin` → `config.cpp`, как [DeBinarizer](DeBinarizer.md) |

Там же общие настройки пунктов: удалять ли исходник, суффикс MLOD (если
исходник остаётся) и раскладка распаковки PBO. Действуют сразу.

Каждый выбранный файл открывает окно консоли с ходом работы. Без замечаний оно
закрывается само; при ошибке или пропуске ждёт Enter, чтобы причину можно было
прочитать.

Пункты пишутся в реестр только для текущего пользователя, без прав
администратора; снимаются тем же выключателем.

### Открытие файлов

Выключатель **«Тулзы в «Открыть с помощью»»** добавляет тулзы в список
«Открыть с помощью» проводника:

| Файл | Тулза | Что делает |
|---|---|---|
| `.pbo` | PBO Unpacker | распаковывает |
| `.p3d` | Model Converter | переводит в MLOD |
| `.bin` | DeBinarizer | разбинаривает |
| `.anm`, `.txa` | ANM Converter | переводит ANM ⇄ TXA |
| `.paa` | Texture Editor | открывает в редакторе |
| `.imageset` | Imageset Editor | открывает в редакторе |

Чтобы файлы открывались тулзой двойным щелчком, выберите её в «Открыть с
помощью» и отметьте «Всегда использовать это приложение». Программу, которая
уже назначена, тулкит сам не заменяет.

Перетащить файл на консольную тулзу (`PboUnpacker.exe`, `ModelConverter.exe`,
`DeBinarizer.exe`, `AnmConverter.exe`, `TextureConverter.exe`) можно и без
выключателя. Файл, открытый так или через «Открыть с помощью», обрабатывается
сразу и с теми же настройками, что пункты меню; окно консоли ведёт себя так же.

## Вкладка «Версии»

- **Канал обновлений:** «Основной» — проверенные версии, «Тестовый» — свежие
  сборки до проверки.
- **Таблица тулз:** какая версия стоит и что с ней (актуальна, есть новая,
  выбрана вручную, ниже поддерживаемой).
- **Выбор версии:** выберите тулзу, версию в списке и нажмите «Установить» или
  «Откатиться». Пока стоит не последняя версия, при каждом запуске будет
  напоминание.
- **«Обновить всё»** — поставить все новые версии разом.

При запуске любой тулзы тулкит сам проверяет обновления (не чаще раза в
6 часов) и показывает одно окно со всеми новыми версиями и их изменениями.
Скачиваются только изменившиеся файлы. «Позже» — окно не появится до следующей
версии.

## Командная строка

```
DevToolkit.exe update check                          что нового у каждой тулзы
DevToolkit.exe update install --all                  поставить всё новое
DevToolkit.exe update install ProjectBuilder@0.1.0   поставить выбранную версию (откат)
DevToolkit.exe update list ProjectBuilder            доступные версии
DevToolkit.exe update channel test                   канал: main или test
DevToolkit.exe menu status                           какие пункты меню включены
DevToolkit.exe menu on pbo p3d                       включить пункты
```

## Важно знать

- Тема окон одна на все тулзы, меняется в [Project Builder](ProjectBuilder.md):
  «Настройки» → «Сборка» → «Тема оформления». Размер каждого окна запоминается.
- Настройки всех тулз — в `%USERPROFILE%\.kr_devtoolkit`.
