# [KR] Model Converter — ODOL → MLOD

Бинаризованные модели (ODOL) → редактируемые (MLOD), с `model.cfg`. Окно —
общее для массовых конвертеров: [как пользоваться](batch_tools.md).

## Что умеет

- ODOL → MLOD, который открывается в Object Builder и Blender.
- Результат — рядом с суффиксом (`x.p3d` → `x_mlod.p3d`) или на место
  исходника.
- **model.cfg:** классы модели и скелеты восстанавливаются из ODOL и пишутся в
  `model.cfg` папки модели. Если `model.cfg` там уже есть — недостающие классы
  дописываются, а класс с тем же именем остаётся как был.

Настройки: «Удалять исходник», «Суффикс MLOD» (пусто — на место исходника,
а исходник уходит в копию), «Перезаписывать готовые результаты».

## Командная строка

```
ModelConverter.exe "P:\мод\data"          MLOD рядом: x.p3d → x_mlod.p3d
ModelConverter.exe x.p3d --delete-source  MLOD на место ODOL, ODOL удалить
ModelConverter.exe x.p3d --suffix ""      MLOD на место ODOL, ODOL — копией в backup
```

Общие ключи — [здесь](batch_tools.md#общие-ключи-командной-строки).

## Важно знать

- Имя класса в `model.cfg` — имя получившегося файла: `x_mlod.p3d` при сборке
  ищет класс `x_mlod`.
- Анимации `model.cfg`, которых в самой модели нет, восстановить неоткуда.
