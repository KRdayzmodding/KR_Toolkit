# [KR] PBO Unpacker — распаковка PBO

Распаковка PBO целиком — до исходников, которые можно править. Окно — общее
для массовых конвертеров: [как пользоваться](batch_tools.md).

## Что умеет

- `x.pbo` → папка `x` рядом. Внутри — дерево по префиксу PBO
  (`x\Автор\Мод\…`, как его видит игра) и `$PBOPREFIX$.txt` в корне аддона.
- Дальше по дереву:
  1. бинарные конфиги → текст, как [DeBinarizer](DeBinarizer.md);
  2. модели ODOL → MLOD на месте, как [Model Converter](ModelConverter.md);
  3. `model.cfg` каждой папки с моделями восстанавливается.
- Раскладка «В папку PBO» — файлы прямо в `x`, без дерева префикса.
- В отчёте видно, чем собран архив, если это записано в его заголовке.

Настройки: «Раскладка» (по префиксу или в папку PBO), «Удалять исходник».

## Командная строка

```
PboUnpacker.exe x.pbo                   → папка x рядом
PboUnpacker.exe "D:\@Мод\Addons"         все PBO папки
PboUnpacker.exe x.pbo --layout flat     файлы прямо в x
PboUnpacker.exe x.pbo --delete-source   и PBO удалить
```

Общие ключи — [здесь](batch_tools.md#общие-ключи-командной-строки).

## Важно знать

- Если папка `x` уже есть, PBO пропускается — распаковка не смешивается с
  чужими файлами.
- Что не удалось перевести, остаётся как лежало в PBO и попадает в отчёт.
- Зашифрованные `.ebo` не распаковываются.
- Обфусцированные PBO распаковываются как есть: испорченные обфускатором имена
  и раскладку тулза не восстанавливает.
