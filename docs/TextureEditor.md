# [KR] Texture Editor — редактирование текстур

Просмотр текстур и работа с ними: SMDI, размер, подбор Френеля.

## Что умеет

Четыре вкладки:

- **Просмотр текстуры** — PAA, EDDS, PNG, TGA, DDS: каналы по отдельности
  (RGBA и каждый канал), мипы, зум, значение пикселя под курсором;
  сохранение в другой формат.
- **Фильтр SMDI по папке** — приводит блик к резкости по SpecularPower у всех
  `_smdi` текстур папки; умеет следить за папкой и обрабатывать новые файлы.
- **Размер текстур** — длинная сторона к выбранной, пропорции сохраняются.
- **Подбор Френеля** — для материала (`.rvmat`).

## Как пользоваться

Откройте текстуру через «Файл» или перетащите её в окно. Для папок — нужная
вкладка и «Выбрать папку». Меню «Правка» — например, перевернуть зелёный канал
(ось Y карты нормалей) или разложить каналы по отдельным файлам.

## Командная строка

```
TextureEditor.exe resize "P:\мод\data" --side 1024   длинная сторона → 1024
TextureEditor.exe smdi "P:\мод\data" --sp 75         фильтр SMDI по папке
TextureEditor.exe invert-green x_nohq.paa            зелёный канал наоборот
TextureEditor.exe split x_smdi.paa                   каналы по отдельным файлам
TextureEditor.exe convert x.paa --out x.png          в другой формат (по расширению)
```

## Важно знать

- Всё, что переписывает файл, сперва кладёт оригинал в папку `_backup` рядом
  (фильтр SMDI — в `_smdi_backup`). Первый оригинал не перетирается никогда.
- Размер: только стороны — степени двойки, папка без подпапок.
- SMDI берёт файлы с `_smdi` в имени; повторный прогон того же файла
  пропускается.
