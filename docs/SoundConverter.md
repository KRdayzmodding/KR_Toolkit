# [KR] Sound Converter — конвертация в OGG

WAV → OGG Vorbis с теми же параметрами, что у звуков игры.

## Как пользоваться

1. Перетащите WAV-файлы или папки в пунктирную зону (вложенные папки тоже
   просматриваются).
2. В «Настройках» выберите **«Куда»**: рядом с WAV или в отдельную папку
   (дерево папок сохраняется).
3. Посмотрите план в таблице, снимите лишние галки и нажмите кнопку внизу.

«Перезаписывать готовые OGG» — без этого готовый OGG не трогается;
перезаписанный уходит копией в `%USERPROFILE%\.kr_devtoolkit\sound_backup`.

## Командная строка

```
SoundConverter.exe ogg "P:\мод\sounds"                OGG рядом с каждым WAV папки
SoundConverter.exe ogg shot.wav step.wav              отдельные файлы
SoundConverter.exe ogg "P:\мод\sounds" --out D:\ogg   в другую папку, дерево сохраняется
SoundConverter.exe ogg ... --dry-run                  план без записи
SoundConverter.exe info shot.ogg                      каналы, частота, битрейт, кодировщик
```

Код выхода: 0 — всё перегнано или пропущено, 1 — есть ошибки.

## Важно знать

- Ошибки копятся и выдаются списком: один битый WAV остальные не останавливает.
- [Project Builder](ProjectBuilder.md) при сборке сам перегоняет WAV, у которых
  нет OGG рядом.
