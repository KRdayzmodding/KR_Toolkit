# [KR] Imageset Editor — атласы иконок интерфейса

Атласы спрайтов интерфейса: `.imageset` и его текстура.

## Что умеет

- Просмотр атласа и правка рамок спрайтов, группы спрайтов.
- Добавление и замена картинок в атласе.
- Сборка атласа из папки картинок.
- Поиск файлов, которые ссылаются на спрайт или сет.
- Путь текстуры внутри `.imageset` — тот, по которому её ищет игра; на диске
  `P:` выводится сам.

## Как пользоваться

Перетащите `.imageset` в окно или откройте его — каждый файл открывается своей
вкладкой. Выберите спрайт на холсте или в списке и правьте его рамку мышью или
числами.

Сохранять — кнопкой справа вверху или Ctrl+S; при закрытии с несохранёнными
правками тулза спросит. Даже после «Не сохранять» правки можно вернуть при
следующем открытии файла — Ctrl+Y. Ctrl+Z отменяет правки и после перезапуска
тулзы — история у каждого файла своя. Если файл изменили в другой программе,
его история сбрасывается.

## Настройки

Шестерёнка справа вверху.

- **Сохранять файлы автоматически** — выключено по умолчанию. Включено — файлы
  сохраняются сами: при переключении вкладки, уходе из окна и закрытии.
- **Шагов отмены на файл** — 50 по умолчанию, до 512.

## Командная строка

```
ImagesetEditor.exe edds icon.png                         EDDS рядом с картинкой
ImagesetEditor.exe edds "P:\мод\data\icons" --out D:\x   папка со вложенными, дерево сохраняется
ImagesetEditor.exe edds icon.png --format DXT5           со сжатием (по умолчанию BGRA8, без потерь)
ImagesetEditor.exe atlas "P:\мод\data\icons\src"         папка картинок → атлас .edds + .imageset
ImagesetEditor.exe unpack x.imageset --out D:\sprites    атлас → PNG по спрайту
ImagesetEditor.exe info x.imageset y.edds                состав и проблемы
```

## Важно знать

- Картинки на вход — всё, что открывает Pillow: PNG, TGA, DDS, BMP, TIFF.
- Атлас вне диска `P:` — путь текстуры нужно дать ключом `--texture-path`.
- Готовый файл не перезаписывается без `--overwrite`; перезаписанный уходит
  копией в `%USERPROFILE%\.kr_devtoolkit\texture_backup\<дата>`.
