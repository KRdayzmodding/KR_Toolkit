# [KR] DevToolkit

Бесплатный набор инструментов для моддинга DayZ. Сборка модов в PBO, подпись,
перегонка текстур, моделей, звука и анимаций, разбинаризация конфигов и
распаковка PBO. Ни DayZ Tools, ни Mikero Tools, ни Python ставить не нужно.

Интерфейс — на русском языке.

## Что внутри

| Тулза | Что делает |
|---|---|
| **[KR] Project Builder** | Запаковка мода в PBO: проверки, исправления, подпись, инкрементальная сборка |
| **[KR] Texture Editor** | Просмотр и редактирование текстур: SMDI, размер, Френель |
| **[KR] Imageset Editor** | Атласы иконок интерфейса: просмотр и правка `.imageset` |
| **[KR] Texture Converter** | Картинки ⇄ PAA/EDDS, сразу много файлов |
| **[KR] Model Converter** | Бинарные модели (ODOL) → редактируемые (MLOD) с `model.cfg` |
| **[KR] DeBinarizer** | `config.bin`, `.rvmat` и другие бинарные файлы → текст |
| **[KR] PBO Unpacker** | Распаковка PBO целиком |
| **[KR] ANM Converter** | Анимации ANM ⇄ TXA |
| **[KR] Sound Converter** | WAV → OGG для игры |
| **[KR] Addon Signer** | Создание ключей и подпись PBO |

Все тулзы открываются из лаунчера **[KR] DevToolkit**. Там же включаются пункты
для правого клика по PBO, P3D и BIN в проводнике.

## Требования

- Windows 10 или 11, 64-бит.
- Для Project Builder — рабочий диск `P:`, как для DayZ Tools и pboProject.
  Остальные тулзы работают с файлами в любой папке.

## Установка

1. Скачайте установщик —
   **[KR_DevToolkit_Setup.exe](https://github.com/KRdayzmodding/KR_Toolkit/releases/download/installer/KR_DevToolkit_Setup.exe)** —
   и запустите. Ссылка постоянная: по ней всегда лежит свежий установщик.
   Ставить его заново не нужно — дальше тулзы обновляются сами.
2. Тулкит ставится в `%LOCALAPPDATA%\Programs\KR DevToolkit` — права
   администратора не нужны. На рабочем столе и в меню «Пуск» появится ярлык
   **[KR] DevToolkit**.

Программы не подписаны сертификатом издателя. При первом запуске Windows может
показать «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в
любом случае». Отдельные антивирусы иногда ошибочно реагируют на программы,
собранные из Python; это ложная тревога.

## Обновления

При запуске тулкит сам проверяет, есть ли новые версии, и показывает одно окно
со списком того, что обновилось, и что нового в каждой тулзе. Скачиваются
только изменившиеся файлы.

На вкладке **«Версии»** в лаунчере:

- **Канал обновлений.** «Основной» — проверенные версии. «Тестовый» — свежие
  сборки до проверки, в них бывают ошибки.
- **Выбор версии.** Любую тулзу можно откатить на прежнюю версию. Пока стоит
  не последняя версия, при каждом запуске будет напоминание.

Если разработчики объявят версию устаревшей (например, в ней нашлась серьёзная
ошибка), тулза при запуске предупредит об этом и объяснит причину.

## Командная строка

У каждой тулзы два файла: `Имя_GUI.exe` — окно, `Имя.exe` — командная строка.
Окно само зовёт командную строку; ею же можно пользоваться из своих скриптов.
Справка — `Имя.exe --help`, например:

```
"%LOCALAPPDATA%\Programs\KR DevToolkit\ProjectBuilder.exe" --help
```

## Где лежат настройки

- Настройки тулз — `%USERPROFILE%\.kr_devtoolkit`.
- Лог и промежуточные файлы Project Builder — `P:\temp`, рядом с модом
  (`<префикс>.kr_build.log`).
- Копии файлов перед исправлением — `P:\temp\.kr_backup`.

## Удаление

«Параметры Windows» → «Приложения» → **[KR] DevToolkit** → «Удалить».
Настройки в `%USERPROFILE%\.kr_devtoolkit` остаются — удалите папку вручную,
если они больше не нужны.

## Для разработчиков тулкита

Этот репозиторий — канал обновлений. `index.json` — список версий, подписанный
ключом выпуска; правка руками сделает его непринятым. Файлы версий лежат в
релизах `<Тулза>-v<версия>`.
